# BlinkIT Grocery Sales Analysis Dashboard

## Project Overview
This project is an interactive Power BI dashboard developed to analyze BlinkIT grocery sales data and visualize key business performance indicators.

## Key Performance Indicators (KPIs)
- Total Sales: 1.20M
- Average Sales: 140.99
- Number of Items: 9K
- Average Rating: 3.92

## Dashboard Visualizations
- **Sales by Item Type:** Compares sales across grocery product categories.
- **Outlet Establishment:** Shows sales trends by outlet establishment year.
- **Fat Content Analysis:** Compares low-fat and regular-fat products.
- **Outlet Size Analysis:** Visualizes sales distribution by outlet size.
- **Outlet Performance Table:** Compares total sales, number of items, average sales, and average ratings across outlet types.

## Filters
- Outlet Location
- Outlet Size
- Item Type
